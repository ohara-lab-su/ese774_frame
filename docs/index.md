`ese774_frame` provides a FastAPI communication framework that exposes a server-side device-control class through
synchronous and asynchronous Python clients. Its primary use is automatic dispatch: with `api_spec=None`, public control
methods and properties are exposed without manually defining a Pydantic request model or an `ApiSpec` for each
operation.

For APIs requiring an explicit HTTP/OpenAPI contract, `ApiSpec` and Pydantic models remain available. Device-specific
routers and clients can customize behavior when necessary.

## DeviceProxy and IDE completion

`DeviceProxy` provides a common entry point for registered device clients. Device-specific `.pyi` files generated by the
framework supply static typing and IDE completion, while the runtime uses the client registry. See the tutorial for
automatic dispatch, `DeviceProxy` registration, and optional `ApiSpec` mode.
